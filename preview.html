02  ·  LLM 원리 + AI 시장 규모
AI의 두뇌, LLM이란?
Large Language Model — 대규모 언어 모델
①
어떻게 만들어졌나 — 수백억 개의 글을 읽다
방대한 텍스트(책, 코드, 뉴스, 논문 등)를 학습하며, 문장 속 다음 단어를 예측하는 과정을 수조 번 반복합니다. 사람이 독서를 통해 지식을 익히는 것과 비슷하지만, LLM은 인간이 평생 읽기 어려운 규모의 데이터를 학습합니다.
②
어떻게 동작하나 — 문맥을 이해해서 답한다
질문을 입력하면 → 학습한 패턴을 바탕으로 → 가장 자연스러운 답을 단어 하나씩 생성합니다. 계산기처럼 정해진 공식이 아니라, 문맥을 이해하여 확률적으로 가장 적절한 문장을 만들어냅니다.
③
한계도 있다 — 완벽하지 않습니다
학습 데이터 이후의 사실은 모름 (Knowledge Cutoff)
가끔 틀린 정보를 자신 있게 말함 (Hallucination)
기본적으로 "대화"만 가능 → 실제 업무 실행은 제한적
따라서 최근에는 Agent, Tool Calling, 코딩 에이전트 기술과 결합되는 추세
💡 한 줄 요약: LLM은 엄청나게 많은 글을 읽고 자란 "텍스트 전문가"입니다.

03  ·  작동 방식 비교 + Roo 자세히 보기
AI 챗봇 vs Roo, 뭐가 다를까?
같은 요청이라도 — 대화로 끝나는가, 실행까지 가는가
💬 일반 AI 챗봇 (ChatGPT · Claude · Gemini)
1
"이 코드 버그 고쳐줘" 라고 질문 입력
2
AI가 수정된 코드를 텍스트로 답변
3
사람이 직접 복사해서 파일에 붙여넣기
4
실행해보고 오류 나면 다시 복붙 → 처음부터 반복
🤖 Roo (코딩 에이전트)
1
"이 버그 고쳐줘" 라고 작업 지시
2
관련 파일을 직접 찾아서 읽고 분석
3
코드 수정 + 터미널 명령 실행까지 직접 처리
4
결과 확인 → 오류 있으면 스스로 재수정 → 완료까지 자동 반복
💡 핵심 차이는 "복붙"입니다. 사람이 AI와 코드 사이를 오가며 연결하던 과정을, Roo는 스스로 끝까지 처리합니다.
