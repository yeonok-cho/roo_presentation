Roo 시작하기 — 4단계면 충분합니다

설치 완료까지 약 10분. 한 번만 하면 됩니다.

1
VS Code 설치
code.visualstudio.com 에서 무료로 다운로드합니다.
전 세계 개발자의 73%가 쓰는 코드 편집기로, 설치 파일을 실행하면 됩니다.
무료
2
Extensions 탭 열기
VS Code 실행 후 Ctrl+Shift+X (Mac: Cmd+Shift+X)를 누르면 확장 프로그램 탭이 열립니다.
앱스토어처럼 필요한 도구를 검색해서 설치하는 공간입니다.
3
"Roo Code" 검색 후 설치
검색창에 Roo Code 입력 후 Install 버튼 클릭.
설치 완료까지 1분 이내입니다.
오픈소스
4
API 키 입력 — 사내 API 사용
사내 API를 사용합니다 → 토큰 무제한, 별도 비용 없음
설정 방법: go/ums 에서 키 발급 후 Roo 설정 화면에 붙여넣기
